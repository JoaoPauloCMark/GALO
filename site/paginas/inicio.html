Por que GALO?

Feita para ser lida em voz alta

Tal qual uma torcida no Brasil grita GALO em voz alta e todo mundo entende, a ideia é esta: claro, direto, lido em alto e bom tom pra qualquer um entender.

🇧🇷

Palavras que você já conhece

defina, se…então, enquanto, para cada, retorne. Acentos são opcionais: então e entao valem igual.

🩹

Erros que ensinam

Toda mensagem diz o que aconteceu, a linha e a coluna — e sugere a correção, como “você quis dizer nome?”.

♾️

Números sem surpresa

Inteiros de qualquer tamanho (2 ^ 1000 é exato) e funções matemáticas com o mesmo resultado, bit a bit, em qualquer sistema.

🌐

Servidor e navegador

O mesmo bytecode roda no servidor e na página. Dois lados, uma linguagem — testada no Chrome, Firefox, Edge e Safari (WebKit).

🧰

Baterias incluídas

Servidor web, banco SQLite, JSON, modelos HTML, segurança e testes automatizados — tudo na biblioteca padrão.

🧩

Editor de verdade

Extensão para VS Code com realce de sintaxe, autocompletar, documentação ao passar o mouse e erros sublinhados enquanto você digita.

Erros que ensinam

O compilador é seu professor particular

Ao lado está uma mensagem de verdade: o servidor deste site acabou de compilar um programa com um nome digitado errado. Repare na posição exata e na sugestão.

  • Erros léxicos, de sintaxe, de significado e de execução, cada um com seu código
  • Linha, coluna e um trecho do código apontando o problema
  • Sugestões concretas, em português, para corrigir
  • Todos os erros de significado aparecem de uma vez, antes de executar

        Comece agora
        
    Do zero ao primeiro programa em um minuto
    
        
    Só precisa do Python 3.10 ou mais novo.
    
        
    
          ⬇ Baixar o GALO (.zip)
          Ver o código no GitHub
        
    
      
    
      
    
        
    
          
    Baixe
    
          
    Baixe o ZIP, descompacte e abra um
             terminal na pasta GALO-main. Ou, com Git:
    
          $ git clone {{ repositorio }}.git
        
    
        
    
          
    Instale
    
          
    Linux e macOS (sem pip):
    
          $ sh instalar.sh
          
    Windows:
    
          > py -m pip install .
          
    Com pressa? Nem precisa instalar: de dentro da pasta, use python3 -m galo
             no lugar de galo.
    
        
    
        
    
          
    Escreva
    
          
    Crie o arquivo ola.galo:
    
          mostre "Olá, mundo! 🐓"
        
    
        
    
          
    Execute
    
          
    E veja a mágica (que não é mágica):
    
          $ galo executar ola.galo
          
    Use também galo repl para conversar com a linguagem.
