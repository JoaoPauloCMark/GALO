Bem-vindo à GALO 🐓

A GALO é uma linguagem de programação em português.

Este instalador coloca no seu Mac:

  • o comando galo, para usar em qualquer pasta pelo Terminal;
  • tudo o que a linguagem precisa para funcionar (não é preciso ter Python instalado);
  • a extensão para VS Code, Cursor ou VSCodium, se algum deles estiver instalado.
